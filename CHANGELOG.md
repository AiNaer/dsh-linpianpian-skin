# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-09-20

- Synchronize with development revision `81604d8`.
- Replace celadon styling with the pine-soot, gilt and warm ivory study design.
- Add matching Linshui library scenes and refined transparent character art.
- Add fixed-density embroidered composer rails and an independent jade emblem.
- Rebuild the sidebar with osmanthus ribbon, complete button frames, fine
  selected-session borders, edge-aligned footer garland and a subdued mascot.
- Add pine/gold content-width handles that animate immediately on hover.
- Add customization protocol support, composer capsule/scroll modes, wide-table
  expansion, settings navigation, boot-error styling and performance guards.
- Add runtime fingerprints, release-local art generation and archive-safe builds.
- Expand lifecycle, asset, packaging and reproducibility checks and update previews.

## 0.1.0 - 2026-08-20

- Prepared the first standalone DeepSeek Harness bundle repository.
- Added the official `dsh.bundle` and `dsh.client` package declarations.
- Added prebuilt host and browser artifacts for build-permission-free GitHub installs.
- Added day/night study scenes, responsive character staging, celadon chrome,
  composer framing, sidebar mascot, and workspace-tree styling.
- Added package-contract and browser lifecycle tests.
- Added bilingual install, development, security, release, and licensing documentation.
