# Security Policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private security-advisory flow for this repository. Do not
open a public issue for an unpatched vulnerability.

Include the affected commit or version, reproduction steps, impact, and any
suggested mitigation. Avoid including real credentials or private Harness
session data.

## Trust model

DeepSeek Harness plugins run as code trusted by the Harness process and Web UI.
Review the source and pin a commit before installing. This skin is designed to
perform presentation-only DOM and CSS work and makes no runtime network calls.
